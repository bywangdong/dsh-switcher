# 2026-10-24 · 分签材质与焦点精修

## 范围

只调整 `src/plugin/switcher.css` 的表面、边线、阴影和过渡。保留 01「分签」的独立项目题签、两行标题、固定状态行、单行原话，以及 Dia 的 942×190 / 182×158 尺寸和完整 11「五拍」图标。没有修改视图、键位、数据适配或动效时间函数。

## 改动

| 表面 | 精修 |
| --- | --- |
| 面板 | 亮色底色改为 `rgb(244 245 247 / 72%)`、暗色 `rgb(30 31 34 / 74%)`；增加只占顶部约四成的微弱高光层。模糊仍为 48px，饱和度从 108% 收到 135%。阴影由一层大扩散改为环境、接触线和 0.5px 描边三层。 |
| 未选中卡 | 从半透明平涂变为独立薄表面：亮色白色 20%、暗色白色 2.5%，各自带 6.5% / 5.5% 内描边。没有加位移或悬浮阴影，避免抢过选中卡。 |
| 选中卡 | 亮色继续压深为 `rgb(33 41 53 / 9.5%)`，不使用早先被否掉的白色卡面；暗色提高到白色 11%。选中级别由 `::after` 单独承担 1px 轮廓、接触阴影和环境阴影，亮色边线 20%，暗色边线 16%。 |
| 题签 | 保留满宽题签；底部增加一条 6% 细线，选中卡题签另用低透明度底色区分，不再依赖整张卡同时变亮。 |
| 过渡 | 选中只在 120ms 内过渡底色和轮廓透明度；`prefers-reduced-motion` 下直接切换。 |
